Colon typing checks

A local fixture for Chrome and Safari. This page has no JavaScript, forms, storage, or network resources.

  1. Type an ordinary sentence quickly. Every character should appear once.
  2. Type hello :fire, press Enter. Expect hello 🔥. Undo once and verify the host’s undo behavior.
  3. Type :wave, press Tab repeatedly, then Enter. Repeat and commit with a closing colon; check that the chosen tone is inserted and remembered.
  4. Type :fire, append zzzzzz, then delete back to :. The existing popup should stay visible with disabled rows. Retype wave; results should become selectable again. Escape should still dismiss it.
  5. Check that the compact popup sits above the caret, moves below near the top edge, and follows the caret on another display.
  6. Type :fire, press Escape, then keep typing. The picker should stay dismissed until a new token boundary.
  7. Type before :fire after, click immediately after :fire, then Enter. Text on both sides should survive.
  8. While a picker is visible, try Command-arrow, Option-arrow, Shift-Tab, and app switching. Native shortcuts and focus should keep working.
  9. Disable Colon in settings while a picker is showing; it should close, and ordinary typing should continue.

The password field should never display Colon candidates or replace its contents.
